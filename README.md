# Practice Round Recap

Public download page for Queen's Business and Corporate Strategy Capsim practice-round coaching reports.

**Live site:** https://thealiahmadi.github.io/capsim-practice-reports/

Students:
1. Choose their section
2. Unlock with their student number
3. Choose industry and team
4. Open or download the HTML report

Student numbers are checked via salted SHA-256 hashes in `unlock.json` (no names or emails on the site). This is a soft gate on a public static site — report files in the repo remain publicly reachable by direct URL.
